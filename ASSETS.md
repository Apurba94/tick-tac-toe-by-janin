# Assets

**Art direction:** Contemporary editorial tabletop-game design inspired by risograph posters and premium stationery. Warm ivory paper, ink black structure, tomato-red X/active accent, cobalt-blue O/counterpoint, offset registration shadows, subtle paper grain.

## Generated assets

- Visual reference image (kept in the Manus workspace, not in this repository).
- `client/public/ttj-monogram.svg` — TTJ brand mark used in the header.

## Implementation note

The board and marks are rendered as crisp UI primitives so gameplay remains accessible and responsive; the generated monogram supplies the branded visual anchor.
