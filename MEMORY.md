# Memory

The selected visual direction is Paper Arcade: warm ivory paper, Fraunces display typography, Space Grotesk utility text, tomato-red X/active states, cobalt-blue O states, and offset print-registration shadows. The title is intentionally written as “Tick tac Toe” with “By Janin” beneath it to match the requested name and brand treatment.

Gameplay is local two-player only. X always starts a new round. The demo query parameter is deterministic and exists only for visual QA. The generated TTJ mark is the primary bespoke visual asset; the board marks remain text-based for crisp scaling and accessibility.
